Radar - Fundamental Analysis & Stock Scanner

A dynamic fundamental screener and scoring platform for Indian equities, built from scratch and run in production since December 2021. Live at radar.definedgesecurities.com.

Problem & role

Problem & users

Retail and semi-professional equity investors need to filter thousands of listed companies by fundamentals (valuation, growth, health, dividends, ownership) and verify an idea's history before acting on it, without building spreadsheets by hand.

My role

Built and own the product end to end since inception: system architecture, the Vue 3 frontend, the Spring Boot/JPA backend, MySQL schema and Flyway migrations, the daily data pipeline, and UAT/production releases via Jenkins.

Architecture

Key engineering decisions

  • Composite scoring across five axes (value, growth, health, dividend, ownership) so a screener result reduces to a comparable score instead of raw parameters.
  • A cached point-in-time fundamentals store lets any saved scanner be backtested by date or symbol list without recomputing historical ratios on the fly.
  • The daily SFTP-to-MySQL pipeline commits per date with derived-ratio recomputation, so a bad or partial day cannot corrupt the rest of the store.
  • Scanners are expressions (arithmetic and logical) over 1,300+ parameters, saved and shareable rather than hard-coded filters.
  • Partner data-feed access is a separate API-key-authorized surface from the authenticated web app, keeping the two consumer types decoupled.
  • JUnit 5 suites run expression evaluation against an in-memory database for speed, with a separate integration suite against a dedicated test database.
