MFZone - Simplifying Mutual Fund Analysis

Discover, analyze and invest: a mutual fund platform covering fund research, comparison and order placement end to end, built from scratch.

Problem & role

Problem & users

Investors need to discover, compare and act on mutual funds in one place, with orders that reliably reach the exchange's registered transfer channel and reconcile back into the platform.

My role

Built the product from scratch end to end: database schema, Java backend API, and the Vue 3 frontend with in-house components, including the BSE StAR MF integration for order flows.

Architecture

Key engineering decisions

  • Owned the schema, API and UI together end to end, keeping data contracts consistent across all three layers instead of integrating against an existing backend.
  • Treated SIP registration, lump-sum orders, order book, reconciliation and cancellation as distinct first-class flows against BSE StAR MF, not a single generic "place order" call.
  • Frontend validations on order placement catch invalid input before it reaches the exchange integration.
  • Fund comparison and current-holdings views were built as reusable in-house Vue components shared across discovery and analysis screens.
