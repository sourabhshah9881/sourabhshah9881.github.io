Definedge Pulse - AI Document Intelligence for Listed Companies

Ingests corporate filings and produces type-aware AI summaries, extracted guidance and WhatsApp alerts, with a REST API for downstream products.

Problem & role

Problem & users

Investors and analysts drown in corporate announcements, concall transcripts, investor presentations and annual reports. Pulse reads these documents and surfaces summaries, management guidance and forward estimates without the user opening each filing.

My role

Built the product end to end: FastAPI backend, Next.js frontend, MySQL storage, Gemini-based summarization and extraction, Razorpay subscription billing, and the pytest suite and Docker deployment.

Architecture

Key engineering decisions

  • Type-aware summarization treats announcements, transcripts, presentations and annual reports as distinct pipelines rather than one generic summarizer.
  • Guidance and forward-estimate extraction carries a confidence score, so downstream consumers can filter on extraction reliability instead of trusting every span equally.
  • A REST API decouples the extraction pipeline from delivery, letting WhatsApp alerts and other downstream products consume the same structured output.
  • Razorpay subscriptions with free-trial gating handle access control without a separate billing system.
  • 100+ pytest cases run against a dedicated test database to keep prompting, parsing and confidence-scoring logic regression-safe.
  • Docker-based deployment keeps releases reproducible across environments.
