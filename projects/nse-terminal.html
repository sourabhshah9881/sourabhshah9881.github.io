NSE Algo-Trading Terminal

A personal Pine Script to Python strategy converter with backtesting, a near-entry scanner, paper trading and gated live order execution.

Problem & role

Problem & users

I write and test strategies in Pine Script (TradingView's charting DSL), but wanted to run them against Cassandra-backed historical and live data, paper trade them, and only then let them place real orders. Built for personal use as a self-contained terminal.

My role

Solo project: the Pine Script to Python converter, the modular bot engine, the Cassandra data layer, the live websocket feed integration, and the monitoring/control web UI.

Architecture

Key engineering decisions

  • A Pine Script to Python converter lets strategies be authored in TradingView's charting DSL and still run through one Python engine for backtests, scanning and live execution.
  • Live order execution is explicitly gated behind paper trading, so an untested strategy cannot place a real order.
  • Cassandra backs both end-of-day and intraday data, chosen for high-throughput time-series writes off a live websocket feed.
  • The bot engine is modular: data ingestion, signal generation and execution are separated so strategies can be swapped independently.
  • A web UI for monitoring and control runs decoupled from the bot engine's own process.
