# Sourabh Shah - Portfolio

Case studies of fintech products I designed and built end to end. Static site served by GitHub Pages.

## What this is

Plain HTML5, one shared stylesheet (`style.css`) and a small vanilla JS file (`theme.js`) for the
dark/light toggle and mockup tab switches. No build step, no framework, no npm dependencies. Every
page works opened directly from `file://` as well as from GitHub Pages.

- `index.html` - intro, project grid, skills, contact.
- `projects/*.html` - one case study per product: problem and role, architecture diagram, key
  engineering decisions, stack, outcomes, and a UI recreation.

## No proprietary code

Every case study describes real products I built, but nothing here is copied from their
codebases. No source code, SQL, schemas, configuration, internal hostnames, credentials, customer
data or business logic from those products appears anywhere in this repository. The "UI
recreation" sections are original HTML/CSS mockups built from scratch with clearly fictional
placeholder data (tickers like ACME LTD, made-up figures), labeled "Illustrative recreation with
fictional data". They do not use any brand assets, logos or screenshots of the real products.
